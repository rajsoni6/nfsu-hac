This folder contains all security documentation for the NFSU Placement
Management System. Each file covers a specific security domain.

--------------------------------------------------------------------------------
FILES IN THIS FOLDER
--------------------------------------------------------------------------------

1. SECURITY_OVERVIEW.txt
   High-level summary of all security controls in the system.
   Start here for a complete picture.

2. AUTHENTICATION_SECURITY.txt
   Password policy, JWT architecture, MFA setup and flow,
   account lockout, session management, student login provisioning.

3. RBAC_ACCESS_CONTROL.txt
   Role definitions, permission matrix, backend and frontend enforcement,
   IDOR prevention, complete route protection table.

4. DATA_PROTECTION_ENCRYPTION.txt
   AES-256 field-level encryption, encrypted fields list, PII access control,
   export data protection, environment secrets management, key generation.

5. INPUT_SECURITY_INJECTION.txt
   Server-side validation (Joi), NoSQL injection prevention, XSS prevention,
   HTTP security headers (Helmet), rate limiting, CORS policy, security tests.

6. AUDIT_LOGGING.txt
   AuditLog schema, complete list of logged actions, access control,
   integrity guarantees, retention policy, how to read audit logs.

7. POLICY_ENGINE_SECURITY.txt
   Placement policy rules, switching rules, offer type restrictions,
   eligibility checks, policy override security, database-driven configuration.

8. SECURITY_CHECKLIST.txt
   Pre-deployment checklist, post-deployment verification,
   periodic security tasks, end-of-session procedures.

9. INCIDENT_RESPONSE.txt
   Incident classification (P1-P4), immediate response steps,
   forensic evidence preservation, secret rotation procedure,
   post-incident review template.

10. SECURITY_INDEX.txt  (this file)
    Index and quick reference.
